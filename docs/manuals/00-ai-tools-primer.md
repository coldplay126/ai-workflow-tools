# AI 코딩 도구 기초

> 이 문서는 AI 코딩 도구를 처음 접하는 팀원을 위한 입문서입니다.
> awf 사용법이 아닌, AI 도구가 **무엇이고 어떻게 동작하는지** 설명합니다.

## 1. AI 코딩 도구란?

AI 코딩 도구는 LLM(Large Language Model)을 이용해 코드를 분석하거나 생성하는 소프트웨어입니다.
사람이 자연어로 지시하면, AI가 코드를 읽고/쓰고/검토합니다.

### 대표 도구

| 도구 | 제공사 | 특징 |
|------|--------|------|
| Claude Code | Anthropic | 터미널 기반 CLI. 파일 읽기/쓰기/실행을 도구(tool)로 수행 |
| Codex CLI | OpenAI | 터미널 기반 CLI. sandbox 환경에서 코드 분석 |
| Cursor | Cursor | IDE 통합. 에디터 안에서 AI와 협업 |
| GitHub Copilot | GitHub/Microsoft | IDE 플러그인. 코드 자동 완성 |

awf은 이 중 **Claude Code**와 **Codex CLI**를 주로 사용합니다.

## 2. 핵심 개념

### 2.1 프롬프트 (Prompt)

AI에게 보내는 지시문입니다. 프롬프트의 품질이 결과 품질을 결정합니다.

```
좋은 프롬프트:
"이 함수의 에러 처리 누락을 찾아주세요. 특히 네트워크 타임아웃 케이스를 확인해주세요."

나쁜 프롬프트:
"코드 봐주세요."
```

### 2.2 컨텍스트 (Context)

AI가 참고하는 정보입니다. AI는 컨텍스트에 없는 것은 모릅니다.

- **파일 컨텍스트**: AI가 읽는 소스 코드
- **대화 컨텍스트**: 이전 대화 내용 (세션 내)
- **설정 컨텍스트**: `CLAUDE.md`, `AGENTS.md` 같은 지시 파일

### 2.3 도구 (Tool)

AI가 실행할 수 있는 동작입니다. 예:
- `Read` — 파일 읽기
- `Edit` — 파일 수정
- `Bash` — 셸 명령 실행
- `Grep` — 코드 검색

Claude Code는 사용자가 승인한 도구만 실행합니다.

### 2.4 토큰 (Token)

AI가 텍스트를 처리하는 단위입니다. 대략 한국어 1글자 ≈ 1~2토큰, 영어 1단어 ≈ 1토큰.
토큰 수가 많을수록 비용이 높고 처리가 느립니다.

## 3. AI 도구의 한계

AI 도구를 효과적으로 쓰려면 한계를 이해해야 합니다.

| 잘하는 것 | 못하는 것 |
|-----------|-----------|
| 패턴 기반 코드 생성 | 비즈니스 의사결정 |
| 코드 리뷰/분석 | 컨텍스트 밖의 추론 |
| 반복 작업 자동화 | 100% 정확도 보장 |
| 문서 초안 작성 | 보안 취약점 완벽 탐지 |

**중요**: AI 결과는 항상 사람이 검증해야 합니다. AI는 "그럴듯하지만 틀린" 답을 줄 수 있습니다(hallucination).

## 4. 파일 기반 워크플로우

awf은 **파일 기반 워크플로우**를 사용합니다. AI 도구에 의존하지 않고, 파일로 상태를 추적합니다.

```
프롬프트 → AI 실행 → 결과 파일 저장 → 사람이 검토 → 다음 단계
```

이 방식의 장점:
- **도구 교체 가능**: Claude → Codex → 다른 도구로 바꿔도 파일은 그대로
- **감사 추적**: 모든 AI 결과가 파일로 남음
- **복구 가능**: AI 세션이 끊겨도 파일에서 이어서 진행
- **수동 재현 가능**: CLI 없이도 같은 프롬프트로 같은 결과를 얻을 수 있음
