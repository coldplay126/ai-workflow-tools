## 품질 체크리스트

분석 결과에 다음 항목이 빠지지 않았는지 확인하세요.

### 보안 및 설정
- [ ] 하드코딩된 URL, API 키, 자격증명이 있으면 반드시 기술 부채에 기록
- [ ] 환경변수 직접 참조 (process.env) 패턴 식별
- [ ] 인증/인가 방식 (Guard, middleware, basic auth 등) 명시

### 완전성
- [ ] 모든 엔드포인트가 api-spec.json에 포함
- [ ] 모든 엔티티/테이블이 data-model.md에 포함 (컬럼 전체)
- [ ] enum, 상수, 타입 코드가 주요 개념에 값 목록으로 포함

### 깊이
- [ ] 각 비즈니스 흐름에 단계별 설명 + ASCII 흐름도
- [ ] 의존성 트리에 직접 의존 + 간접 의존 구분
- [ ] 기술 부채에 심각도(High/Medium/Low) + 구체적 위치(파일:라인 또는 메서드명)

### 코드 흐름 분석
- [ ] 런타임 오류 가능성 (null 접근, undefined, 타입 불일치)
- [ ] 비결정적 동작 (정렬 없는 조회, race condition)
- [ ] 부작용 (객체 mutate, 전역 상태 변경)
- [ ] 에러 핸들링 누락 (try-catch 없는 외부 호출)
